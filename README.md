# Still Lit
双击 index.html 或使用 VS Code Live Server 打开。

全站 Lora，标题 Medium（500），正文 Regular（400），文字居中。灯具文字和 info 使用半透明白色柔边框。
18 盏变色灯：01、02、04、05、07、08、09、20、21、22、25、26、27、29、32、38、41、43。其余 26 盏显示确认的摘录，页面不显示出处。

正文和颜色在 lamps.js 修改。collection.png 为编号图。Info 文案在 index.html 修改。
每盏灯独立移动，悬停 0.2 秒暂停当前灯，0.5 秒显示文字或变色。关灯冻结，开灯继续。Info 只在黑色页出现，点击框外收起。

摘录来源为用户提供的聪3.docx。13 与 42 的文字谈及其他设计作品，是形态联想，不代表照片中灯具的设计归属。图片使用此前内置 imagegen 抠图素材。

Info 框为 90% 白色，灯具框为 82%。Lora 通过 Google Fonts 加载，需要网络；无法加载时使用系统衬线字体。来源信息仍保存在 lamps.js 中，便于查阅。
